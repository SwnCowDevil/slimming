# 小程序验收清单

## 身份与数据隔离

- [ ] 首次打开调用 `wx.login` 并创建内部用户 UUID。
- [ ] 同一微信用户重新登录后内部 UUID 不变。
- [ ] 点击“使用微信资料”后才请求昵称和头像。
- [ ] 两个测试微信用户看不到彼此的餐食、体重和申请。

## 核心流程

- [ ] 完成五步建档后进入“今日”。
- [ ] 食品搜索、克数调整和餐别选择可以保存一餐。
- [ ] 网络失败时记录保留在本地草稿，恢复后可重试。
- [ ] 日历可切周/月，记录状态在日期上可辨识。
- [ ] 7/30/90 日趋势切换正确，图表触摸提示可读。
- [ ] AI 建议始终先成为草稿，确认前不写餐食。
- [ ] 食物估重可按类别切换参照物、调整份数，并带日期进入食物搜索。

## 视觉与兼容性

- [ ] iPhone 小屏和常见安卓机无横向滚动或遮挡。
- [ ] 字号、字重、浅色背景与 `superdesign/` 参考一致。
- [ ] wx-calendar 和 wx-charts 的浅色主题与页面统一。
- [ ] 加载、空状态、错误状态和按钮禁用状态清楚。
- [ ] 微信开发者工具“详情 → 本地设置”开启 npm 构建后编译无错误。
